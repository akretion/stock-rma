This module allow to create categories and subcategories for RMA.
The goal is to be able to classify/organize the RMAs and have some statistics. there is not more logic added to these categories.
The name 'category' is generic enough so it is up to you to decide on what kind of data you want your statistics.

Example of use case : the category could be the responsible/source (the supplier, the carrier, the manufacturing...) and the sub-category could be a more detailed flaw on the product.

The list of subcategory depend of the chosen category, but a subcategory could be shared between categories.
